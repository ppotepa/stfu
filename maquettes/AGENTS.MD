# Maquettes agent instructions

This subtree contains HTML/CSS/JS UI prototypes, not production Avalonia code.

Use this subtree only for:

- target screen layout
- visual interaction prototypes
- panel/tab behavior
- design language references

Do not infer production architecture only from a maquette. Translate prototype behavior into `src/runtime/STFU.UI/` and keep engine/NPR logic in `src/aot`.

For UI implementation tasks, inspect the specific maquette folder, then inspect the corresponding Avalonia code.
