# STFU Maquettes

Interactive HTML maquettes for planned STFU screens.

## Views

- [Workspace](workspace/index.html): main viewport, NPR inspector, right-side protruding tabs.
- [Pipeline Graph](pipeline-graph/README.md): future isolated NPR pipeline and graph-flow debug view.
- [Preset Browser](preset-browser/README.md): future preset registry, metadata, and preset editing flow.
- [Asset Browser](asset-browser/README.md): future mesh asset registry, loader status, and assignment flow.
- [Debug Graph](debug-graph/README.md): future NprGraph counters, overlays, determinism, and trace view.
- [Export](export/README.md): future stroke frame export and SVG/output review flow.

Each view lives in its own folder so future screens can evolve independently.
